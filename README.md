# Shunno Browser (শূন্য ব্রাউজার)

**Shunno Browser** (`v1.0.0`) is a lightweight, fast desktop web browser and multi-threaded download manager for Windows 10 & 11.

## Direct Download
- **[Download ShunnoBrowser.exe](https://github.com/asanaim/ShunnoBrowser-Windows/releases/latest/download/ShunnoBrowser.exe)**

## Key Features
- **Floating Media & File Download Pill (`Shunno Get`):** Hovering over any video player, audio stream, or downloadable file link displays a floating download badge with live HTTP file-size probing (`MB` / `GB`) and up to 32-thread parallel downloading.
- **Pre-Roll YouTube Ad Stripping & Background Media Play:** Strips `adPlacements` and `playerAds` from YouTube player responses before playback starts, blocks ad/tracker network requests natively, and keeps background audio playing when minimized.
- **Custom Search Engines:** Switch between DuckDuckGo, Google, Startpage, Bing, YouTube, or add your own custom `%s` search engine.
- **Full Dark Mode & Per-Site Controls:** Toggle Full Dark Mode across both the browser toolbar and web pages, plus per-site JavaScript, Images, Desktop User-Agent, and Cookie Banner rejection.
